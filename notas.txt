git unit -> inicia el repo local

git branch -M [nombre] -> cambia el nombre de la rama actual
git branch --list -> listear ramas locales
git branch --all -> listar ramas locales y remotas
git remote add origin <link> -> agrega un vonculo remoto para el repositorio
hit push -u origin [nombre-rama] -> "sube" la rama local al remote (estose hace una sola vez)
git push -> sube los cambios al remote
